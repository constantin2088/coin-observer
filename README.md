# 币观

轻量的加密货币行情观察工具，适合电脑浏览器日常看盘和发现异动。使用克制的暗色界面、北京时间与中文金额单位，红涨绿跌。

## 功能

- 市值前 100 币种行情、中文搜索、自选、涨跌与成交额排行。
- K 线涵盖分钟、小时、日、周、月、年周期，支持十字定位、缩放、拖动、历史加载和全屏。
- 异动观察支持成交额门槛、仅看自选和排除常见稳定币。
- 到价提醒支持 CoinGecko 美元综合报价和 OKX USDT 现货报价，可启用提示音、桌面通知并查看触发记录。
- 本机行情缓存、设置记忆、自选与提醒备份导入导出，以及舒适／紧凑布局。

## 启动

需要 Node.js **22.13 或更新版本**，以及联网获取公开行情。

Windows：下载源码并解压到一个文件夹，双击 **启动币观.bat**。首次启动会安装依赖并构建，之后复用构建文件。浏览器自动打开，请保留启动窗口。

其他环境或手动启动：

```sh
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:8787`。详细操作见 [使用说明](使用说明.md)。

## 数据与存储

看板采用 CoinGecko 的美元综合报价，K 线采用 OKX 的 USDT 现货报价，二者可能不同。K 线与 OKX 提醒目前支持 14 个币种，年 K 线由月 K 线汇总。

自选、提醒、设置和行情缓存保存在当前浏览器。提醒需要页面保持打开；页面关闭、电脑休眠或数据更新中断时不能保证及时触发。桌面通知需浏览器授权，并受系统通知设置影响。公开行情接口的可用性和刷新速度由数据源决定。

无需交易账户密码或 API Token，仅观察公开行情，不提供交易下单。
