# 币观 v1.1.0

轻量的加密货币行情观察工具，适合电脑浏览器日常看盘和发现异动。使用克制的暗色界面、北京时间与中文金额单位，红涨绿跌。

## 功能

- 市值前 100 币种行情、中文搜索、自选、涨跌与成交额排行。
- K 线涵盖分钟、小时、日、周、月、年周期，支持十字定位、缩放、拖动、历史加载和全屏；可调均线与 MACD／RSI 副图、最新价线、未收盘标识、整数／自动精度收盘价。
- 异动观察支持 1 小时／5 分钟／15 分钟、短时成交额放大门槛、自选和稳定币筛选，保留最近 100 条异动记录。
- 价格提醒支持 CoinGecko 美元综合报价和 OKX USDT 现货报价，可编辑、暂停、重新启用，或按创建时基准价的百分比设置目标；支持提示音、桌面通知和触发记录。
- 本机行情缓存、设置记忆、自选与提醒备份导入导出，以及舒适／紧凑布局。

## 启动

需要 Node.js **22.13 或更新版本**，以及联网获取公开行情。

Windows：下载源码并解压到一个文件夹，双击 **启动币观.bat**。首次启动会安装依赖并构建，之后复用构建文件。浏览器自动打开，请保留启动窗口。

其他环境或手动启动：

```sh
npm ci
npm run build
npm start
```

默认打开 `http://127.0.0.1:8787`。Windows 启动器遇到端口冲突时自动从 8787～8797 中选择可用端口，并记忆选择。浏览器存储按地址隔离，切换端口时可导入备份恢复自选和提醒。详细操作见 [使用说明](使用说明.md)。

## 数据与存储

看板采用 CoinGecko 的美元综合报价，K 线采用 OKX 的 USDT 现货报价，二者可能不同。K 线、OKX 提醒和短时异动目前支持 14 个币种，年 K 线由月 K 线汇总。5／15 分钟异动按最新完整 5 分钟 K 线计算，放量倍数比较之前 12 根完整 K 线的平均成交额，15 分钟按等长窗口换算；不代表实时逐笔行情。

自选、提醒、设置、异动记录和行情缓存保存在当前浏览器。行情缓存自动限制到约 3 MB、最多 48 项，支持单独清理；自选和提醒保留。单个图表最多加载约 3000 根 K 线，本机缓存保留最近 1500 根。提醒需要页面保持打开；页面关闭、电脑休眠或数据更新中断时不能保证及时触发。桌面通知需浏览器授权，并受系统通知设置影响。公开行情接口的可用性和刷新速度由数据源决定。

无需交易账户密码或 API Token，仅观察公开行情，不提供交易下单。

## 验证

```sh
npm test

npm run build
npx playwright install chromium
npm run test:e2e
```

Windows 启动检测回归：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/launcher.test.ps1`。GitHub 自动检查涵盖数据、类型、构建、浏览器交互及 Windows 启动逻辑。浏览器操作使用固定测试行情，不依赖第三方服务在线；真实行情的可用性另行检查。

本机日志、备份、环境文件、构建产物和 Sites 元数据已排除在版本控制之外。
